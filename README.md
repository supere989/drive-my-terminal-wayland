# drive-my-terminal-wayland

Give an AI agent its **own** mouse cursor, keyboard and input focus on a Wayland
desktop (KDE Plasma / KWin), running concurrently with the human's real input —
no focus stealing, no interference.

**Status:** pre-implementation. See [`SPEC.md`](SPEC.md) (architecture + phases)
and [`CLAUDE.md`](CLAUDE.md) (original agreed direction).
